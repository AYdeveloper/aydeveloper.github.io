🧾 chatgpt-receipts - See Which AI Really Answered

A Chrome extension that shows which model actually answered each ChatGPT reply, and flags it when you get rerouted.

Download chatgpt-receipts

Simple visibility for everyday ChatGPT use on Windows. No coding required.

🔍 What This Extension Does

chatgpt-receipts adds a small, clear label to each ChatGPT reply so you can see which model actually answered. It acts like a receipt for your conversation. Instead of guessing which model handled a response, you get a visible note next to the reply.

The extension also watches for rerouting. Rerouting means ChatGPT may switch your request to a different model than the one you expected. When that happens, chatgpt-receipts flags it so you can tell at a glance that the answer came from a different model.

You do not need to change how you use ChatGPT. You keep typing in the same ChatGPT window on Windows, and the extension adds helpful labels where you already read replies.

💡 Why This Matters

Different models can give different answers, different levels of detail, and different styles. If you are comparing answers, testing prompts, or simply want to know what happened, a visible model label removes the guesswork.

The reroute flag is especially useful when you expect one model but receive a reply from another. You can see the switch immediately and decide whether to retry, rephrase, or keep the answer. This makes your ChatGPT sessions easier to understand without any technical setup.
